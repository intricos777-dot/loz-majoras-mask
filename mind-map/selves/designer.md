# Self: The Designer

**Role:** The aesthetic compass. Decides how it *feels* before it's coded.

## Evidence

- Tron-grid world hub, cyan/amber/violet palette, world beams, "resonance" meters. `[obs]`
- Command deck per world with themed skins (frame styles: classic, chisel, gothic, etched, stitched, hollow). `[obs]`
- ANSI truecolor + box-drawing everywhere — the game *is* the terminal. `[obs]`
- Boss music = `[shambler]` + `music:` field; idle/combat/boss trios per world. `[obs]`
- Keyblade collection: 17 blades, Ultima Keyseal as the 18th reward, drive forms (shadow/ultima/twilight). `[obs]`

## Frameworks exercised

- **[World-synced decks](/frameworks/world-synced-decks.md)** — UI *and* combat change skin with the world.
- **[Melodic fields] — music matches emotion.**

## Notes

- The Designer notably prefers the *hub-and-spoke*: a central place, satellites
  around it, and each satellite carries its own identity. That pattern appears
  in both the world hub and the world-themes map. `[infer]`
- The game design pins: keyblade loot as identity, drive forms as mastery,
  memory-steal as cost. `[obs]`
