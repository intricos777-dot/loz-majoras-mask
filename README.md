# The Legend of Zelda: Majora's Mask
Remaster build with updated shaders and graphics based on the Twilight Elysium engine.

## Features
- Updated shader pipeline from Twilight Elysium
- Cleaner graphics and lighting
- 3-day cycle enhancements
- Modern resolution support
- Self-healing and debugging wrappers included

## Status
Scaffold only. No proprietary assets included.
